# Shoply 

A shopping app built with Flutter.

## Features
- Splash, onboarding, login, sign up (with profile photo) and password reset
- Browse categories and products, product details with image slider
- Favorites and shopping cart with checkout
- My Orders with Active / Completed filters
- Profile update, change password, settings, about, contact us

## Tech
- Flutter
- Firebase Authentication and Cloud Firestore
- Supabase Storage (profile photos)
